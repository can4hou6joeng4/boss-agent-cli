# Default to Low-Risk Assistance Mode

Status: **Superseded by the 2026-08 open-capability workflow design.** Retained as historical context only; current assisted/research modes have identical capability access.

The project previously used **Low-Risk Assistance Mode** as an execution gate: sensitive commands remained restricted compatibility surfaces and were blocked by default. This behavior is historical; the superseding design keeps the risk metadata but gives `assisted` and `research` identical access to implemented capabilities.
