01 · 核心能力

为 Agent 设计的每一处

  1. 福利筛选不是关键词命中，是真实匹配

    --welfare 双休,五险一金 自动翻页补抓详情，按 AND 逻辑做真实匹配。

  2. JSON 信封一种形状，所有命令

    stdout 只输出统一 JSON 信封；boss schema 提供当前能力与后继动作。

  3. 本地候选池你的清单，留在你的机器

    保存、标记、离线对比候选岗位，并用漏斗统计复盘求职进展。

  4. AI 求职增强更安静的一种帮助

    JD 分析、简历润色、定向优化、模拟面试，支持 OpenAI 兼容接口与 Ollama / vLLM 本地模型。

  5. 平台抽象一套 CLI，可扩展平台

    Platform / RecruiterPlatform 双注册表 + --platform 全局选项，当前平台为 zhipin。

  6. Agent 接入四道门，同一套能力

    CLI · JSON · MCP · Python API，四条入口调用同一套能力与状态。

02 · 运行边界

每一步，都有掌控

已实现的工作流开放使用；未支持能力会明确返回。遇平台风险立即停止并保存断点，风险解除后由用户显式恢复。

  1. 1本地状态登录态、缓存、简历和候选池保存在本机。
  2. 2双角色工作流求职者与招聘者调用已实现的搜索、简历与沟通能力。
  3. 3有限运行长流程受超时、重试、预算、断点与停止条件约束。
  4. 4不规避风控命中风险码或安全页即停止当前流程并保存断点。
  5. 5显式恢复风险状态解除后，由用户显式恢复任务。
  6. 6状态可复用向导、CLI 与 Agent 共用工作流和本地状态。

04 · 常见问题

问与答

它会自动投递或打招呼吗？
支持已实现的沟通与投递能力，具体参数以 boss schema 为准。批量和长流程受固定预算、超时与停止条件约束；遇平台风险立即停止并保存断点。
AI Agent 怎么调用？
通过 subprocess 调用 CLI：先 boss schema 读能力，再解析 stdout 的 JSON 信封；也支持 MCP 与 Python SDK。
支持哪些平台与 AI 模型？
当前平台为 zhipin（BOSS 直聘），支持求职者与招聘者。AI 可配置 OpenAI 兼容接口或 Ollama / vLLM 本地模型。
需要什么环境？
Python ≥ 3.10；登录、导出及已声明的浏览器工作流按需使用 Patchright 内核（patchright install chromium）。
开源吗？
MIT，完全开源免费。欢迎 Star、Issue 和 PR。

更多细节见 GitHub README 与 docs/。
